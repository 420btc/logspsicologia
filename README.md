## ✨ Características

### 🏗️ **Módulos del Sistema**

- **🧠 Arquitectura del Sistema** - Explora los componentes principales de la mente
- **💾 Sistema de Memoria** - Analiza memoria consciente e inconsciente  
- **🌙 Procesos de Mantenimiento** - Investiga cómo los sueños mantienen el sistema
- **🔗 Registro Temporal** - Blockchain de experiencias vitales
- **❤️ Sistema Emocional** - Emociones como metadatos del sistema
- **👤 Sistema de Personalidad** - Rasgos, arquetipos y patrones
- **👥 Red Neuronal Social** - Conexiones e interacciones sociales
- **👁️ Procesamiento Sensorial** - Sistemas sensoriales e integración
- **⚡ Sistema de Recompensas** - Motivación y formación de hábitos
- **💡 Sistema de Metacognición** - Pensamiento sobre el pensamiento

### 🎯 **Funcionalidades Clave**

- 🖥️ **Terminal Interactiva** - Interfaz de línea de comandos estilo hacker
- 🔍 **Exploración Modular** - Navega entre diferentes sistemas mentales
- 📊 **Análisis en Tiempo Real** - Logs de depuración del sistema mental
- 🎨 **UI Moderna** - Diseño cyberpunk con efectos visuales
- 📱 **Responsive** - Funciona en desktop y móvil

## 🚀 Instalación

### Prerrequisitos

- Node.js 18+ 
- npm o pnpm

### Configuración Rápida

```bash
# Clonar el repositorio
git clone https://github.com/420btc/logspsicologia.git
cd logspsicologia

# Instalar dependencias
npm install
# o
pnpm install

# Ejecutar en modo desarrollo
npm run dev
# o
pnpm dev
```

Abre [http://localhost:3000](http://localhost:3000) en tu navegador.

## 🎮 Uso

### Comandos Básicos

```bash
# Ver módulos disponibles
modulos

# Acceder a un módulo específico
arquitectura
memoria
emociones

# Ver ayuda contextual
ayuda

# Limpiar terminal
limpiar
```

### Navegación por Módulos

Cada módulo tiene sus propios comandos específicos:

```bash
# En el módulo de memoria
tipos          # Ver tipos de memoria
consciente     # Analizar memoria consciente
subconsciente  # Analizar memoria subconsciente

# En el módulo emocional
taxonomia      # Ver taxonomía emocional
analizar       # Iniciar análisis emocional
miedo          # Analizar emoción específica
```
